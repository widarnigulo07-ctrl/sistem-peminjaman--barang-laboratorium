# sistem-peminjaman--barang-laboratorium

**Deskripsi Sistem**

Sistem Peminjaman Barang Laboratorium adalah aplikasi berbasis web yang digunakan untuk mengelola proses peminjaman barang laboratorium.

Sistem ini memiliki dua aktor utama yaitu:

1. **Mahasiswa/Peminjam**

   * Melihat daftar barang yang tersedia.
   * Mengajukan peminjaman barang.
   * Mengunggah dokumen atau berkas peminjaman.
   * Melihat status pengajuan.
   * Melihat riwayat peminjaman.

2. **Admin/Petugas Laboratorium**

   * Mengelola data barang.
   * Melihat daftar pengajuan peminjaman.
   * Memeriksa berkas peminjaman.
   * Menyetujui atau menolak pengajuan.
   * Mengelola proses pengembalian barang.

---
3. **Tujuan Sistem**

Tujuan dari pembuatan sistem ini adalah:

* Mempermudah proses peminjaman barang laboratorium.
* Mengurangi kesalahan pencatatan data secara manual.
* Membantu admin dalam mengelola data barang dan peminjaman.
* Memberikan informasi status peminjaman secara cepat.
* Menerapkan konsep Cloud Computing dalam pengembangan sistem.

---

4. **Fitur Sistem**

### Fitur Mahasiswa/Peminjam

* Login ke sistem.
* Melihat daftar barang laboratorium.
* Mengajukan peminjaman barang.
* Upload dokumen peminjaman.
* Melihat status pengajuan.
* Melihat riwayat peminjaman.

### Fitur Admin/Petugas Laboratorium

* Login admin.
* Mengelola data barang.
* Melihat data peminjaman.
* Melakukan verifikasi berkas.
* Approve peminjaman.
* Reject peminjaman.
* Mengelola pengembalian barang.

---

 5. **Teknologi yang Digunakan**

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Framework Web (Laravel/PHP)
* **Database:** MySQL
* **Cloud Computing:** Deployment menggunakan layanan cloud
* **Version Control:** GitHub

---

 6. **Manfaat Sistem**

Dengan adanya sistem ini diharapkan:

* Proses peminjaman barang menjadi lebih cepat.
* Data peminjaman tersimpan dengan baik.
* Admin lebih mudah melakukan monitoring barang.
* Mahasiswa dapat mengetahui status peminjaman secara online.
* Sistem dapat diakses kapan saja melalui internet.
